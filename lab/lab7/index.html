Welcome, Data Detective! The organizers of the HarmonyFest Global Music Tour are in a panic. Their primary database suffered a corruption event just days before artist payouts are due. The raw regional ticket sales export they managed to recover contains missing values, null strings, and dates completely stripped of standard formatting.

Your objective is to create an Alteryx workflow that takes this messy input data and prepares it for the financial analysis team. You must standardize the temporal data, handle null payment strings by substituting the most common purchase method, and repair missing financial values using mathematical averages. Be mindful of how your data type choices impact downstream calculations.

Standard Lab Requirement: Annotation You must annotate every Alteryx tool you drop onto the canvas. Use the tool's annotation configuration to write a brief, clear sentence explaining exactly what that step is doing. Workflows submitted without annotations will lose points.

Steps 3 & 4: Date Parsing

3

Convert Order Date

The current date is stored as a string, preventing us from using temporal formulas. Drag a DateTime tool onto the canvas.

  • Select the field that contains your order date string.
  • Choose the conversion direction: String to Date/Time format.
  • Select the format that matches your incoming data exactly: MM/dd/yyyy.
Reveal Tool Hint -0.1 pt Penalty
4

Extract Weekday Name

Management wants to know which days of the week generate the most ticket sales. Drag a second DateTime tool onto the canvas.

  • Select the new proper Date column you generated in Step 3.
  • Choose the conversion direction: Date/Time format to String.
  • Use the custom format box to extract just the abbreviated weekday name (e.g., Sun, Mon). In Alteryx date formatting, this is represented by abbreviated Day.
  • For more information, refer to the Alteryx Documentation or the DateTime Specifiers guide.

Steps 5 & 6: Data Imputation

Checkpoint 2: Data Discovery

What is the most popular ticket purchase method observed in the dataset?

5

Replace Null Strings (Purchase Method)

We have missing data in the purchase_method column. Management wants us to assume the most common payment type for missing records. Drag a Formula tool onto the canvas.

The Formula tool allows you to create new columns, update existing columns, and use expressions (like IF statements or math calculations) to manipulate your data. You can find it in the Preparation tool palette at the top of your screen.

// Formula logic to handle missing string values: IF IsNull([purchase_method]) THEN "Credit" ELSE [purchase_method] ENDIF
6

Replace Null Numeric Values

Some ticket sales records are missing their final numeric amount. We need to substitute these gaps with the mathematical average. Drag an Imputation tool onto the canvas.

The Imputation tool is designed specifically to easily replace missing (Null) values with a specified string or a calculated statistical value like an average or median. You can find it in the Preparation tool palette.

  • Select the target numeric column containing the null sales values.
  • Choose to replace Null() values.
  • Set the replacement value to the Average.

Checkpoint 3: Imputation Ethics

You just replaced missing financial data with an average value. What is the potential risk or analytical bias introduced by substituting missing sales figures with a mathematical average rather than investigating the root cause?

Steps 7 to 11: Formatting & Delivery

7

Clean Structure

Our dataset now has original columns mixed with new ones we generated. Drag a Select tool to clean the structure before outputting.

  • Remove the redundant original string date columns.
  • Rename columns so they are clean and professional (e.g., remove underscores).
  • Reorder the columns so Order ID is first, followed by the Date, Weekday, Method, and Amount.
  • Ensure numeric columns are properly set to an appropriate numeric Type (like Double).

Filter Data

  • Configure the Basic Filter to target the purchase_method column.
  • Set the operator to Equals (=).
  • Type Cash into the value field.

Output

Critical Step: Make File Paths Relative

If you submit your file with absolute paths, the workflow will break on the grader's computer. You must make paths relative so the workflow can be graded:

  1. Ensure your workflow is saved in the same Project folder as your datasets.
  2. In Alteryx, click Options in the top menu bar.
  3. Navigate to Advanced Options > Workflow Dependencies.
  4. Click the All Relative button at the bottom of the window.
  5. Click OK and immediately Save your workflow (.yxmd) one last time.
