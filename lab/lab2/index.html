We are closing the books on the first half of fiscal '25. I have attached the raw sales ledger above. It contains detailed transaction data across our global markets. Please perform a detailed Pivot Table analysis to break down the performance of our iPhone and Mac lines.

Analyst Task List (Requirements)

Instructions: Each task below includes a brief "Challenge Mode" instruction. If you are stuck, click "Need Step-by-Step Help?" to reveal detailed steps.

Note: To ensure your workbook is clean, please create a separate Pivot Table for each task below.

  • 1. Data Setup
    Convert the raw data range into an Excel Table and name it "AppleSales".
    Need Step-by-Step Help?
    1. Download the Excel file.
    2. Click anywhere inside the data.
    3. Press Ctrl+T (or Cmd+T on Mac) and click OK.
    4. In the Table Design tab (top ribbon), find the "Table Name" box on the far left and type "AppleSales".
  • 2. Revenue & Cost Calculation
    Create two new calculated columns in your table: Revenue (Units * Price) and COGS (Units * Cost).
    Need Step-by-Step Help?
    1. In cell I1 (or next to the last column), type "Revenue" and press Enter.
    2. In the first empty cell under Revenue, type =[@Units]*[@Unit_Price] and press Enter.
    3. Repeat for "COGS" using the formula =[@Units]*[@Unit_Cost].
  • 3. Regional Grouping
    Create a Pivot Table showing Revenue by Country. Manually group countries into Americas, Europe, and Asia Pacific.
    Need Step-by-Step Help?
    1. Insert a Pivot Table. Drag Country to Rows and Revenue to Values.
    2. Group Americas: Hold Ctrl/Cmd and select USA, Canada, Brazil, Mexico. Right-click > Group. Rename "Group1" to "Americas".
    3. Group Europe: Select UK, France, Germany, Italy, Spain. Right-click > Group. Rename to "Europe".
    4. Group Asia: Select China, Japan, Australia, South Korea, India. Right-click > Group. Rename to "Asia Pacific".
  • 4. Channel Volume
    Show the Count of Transactions broken down by Channel.
    Need Step-by-Step Help?
    1. Drag Channel to Rows.
    2. Drag Channel (again) or Transaction ID to Values.
    3. Ensure the aggregation is set to Count (not Sum).
  • 5. Pricing Strategy (Bar Chart)
    Calculate the Average Unit_Price for each Product. Insert a Clustered Bar Pivot Chart to visualize this.
    Need Step-by-Step Help?
    1. Drag Product to Rows and Unit_Price to Values.
    2. Right-click the values column > Summarize Values By > Average.
    3. Click inside the Pivot Table > Insert > PivotChart > Bar > Clustered Bar.
  • 6. Profitability (Calculated Field)
    Create a Calculated Field named "Gross Profit" that subtracts COGS from Revenue. Show this by Product.
    Need Step-by-Step Help?
    1. Create a NEW Pivot Table with Product in Rows.
    2. Go to PivotTable Analyze tab > Fields, Items & Sets > Calculated Field.
    3. Name: "Gross Profit".
    4. Formula: = Revenue - COGS (Double click fields to insert them).
  • 7. Product Mix & Slicers
    Show Revenue Share % by Product (Pie Chart).
    New: Add a Slicer for "Product" to filter the chart.
    Need Step-by-Step Help?
    1. Drag Product to Rows and Revenue to Values.
    2. Right-click a number in Values > Show Values As > % of Column Total.
    3. Insert > PivotChart > Pie.
    4. Insert Slicer: Click inside Pivot Table > PivotTable Analyze > Insert Slicer > Check "Product" > OK.
  • 8. Monthly Trends (Line Chart)
    Show Monthly Revenue trends (group by Month only). Create a Line Pivot Chart to visualize.
    Need Step-by-Step Help?
    1. Drag Date to Rows and Revenue to Values.
    2. Ensure Excel groups by Months. Remove "Year", "Quarter", and "Date" fields from the Rows area so only Months remain.
    3. Insert > PivotChart > Line.
  • 9. Visual Audit (Heat Map)
    Apply Green-White-Red Color Scale conditional formatting to your Profit values (Task 6) to identify high performers.
    Need Step-by-Step Help?
    1. Highlight the Profit numbers (do not select the Grand Total).
    2. Home tab > Conditional Formatting > Color Scales.
    3. Select the first option (Green for high, Red for low).
  • 10. Audit Drill Down
    Perform a drill-down audit on the "Americas" revenue total. Count the resulting rows in the new sheet.
    Need Step-by-Step Help?
    1. Go to your Regional Grouping table (Task 3).
    2. Double-click directly on the numeric total for "Americas".
    3. Excel will create a new sheet. Count the rows in this table.
  • 11. Monthly Growth Analysis (%)
    Create a new Pivot Table showing Total Revenue by Month. Set the values to show the % Difference From the previous month.
    Goal: Identify the growth percentage for April. Round to 1 decimal place (e.g., 0.5%).
    Need Step-by-Step Help?
    1. Drag Date (Month) to Rows and Revenue to Values.
    2. Right-click any number in the Revenue column.
    3. Select Show Values As > % Difference From...
    4. In the dialog box:
    - Base Field: Date (or Months)
    - Base Item: (previous)
    5. Click OK. Read the percentage for April.
