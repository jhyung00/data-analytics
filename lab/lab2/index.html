Detailed Solution Steps

Task 3: Regional Analysis

Insert > PivotTable. Drag Region to Rows and Revenue to Values.

Task 4: Channel Volume

Drag Channel to Rows and Channel (again) to Values. Ensure it says "Count of Channel". If it says Sum, click Value Field Settings > Count.

Task 5: Pricing Strategy

Drag Product to Rows and Unit_Price to Values. Right-click the values column > Summarize Values By > Average.

Task 6: Profitability (Calculated Field)

Click inside Pivot. Go to PivotTable Analyze tab > Fields, Items & Sets > Calculated Field. Name it "Gross Profit". Formula: =Revenue - (Units * Unit_Cost).

Task 7: Product Mix (%)

Drag Product to Rows and Revenue to Values. Right-click a number in the column > Show Values As > % of Column Total.

Task 8: Monthly Trends

Drag Date to Rows. If Excel shows individual dates, Right-click any date cell > Group... > Select "Months".

Task 9: Visual Audit

Select the numbers in the Profit table (exclude Grand Total). Home > Conditional Formatting > Color Scales > Select Red-White-Green.
