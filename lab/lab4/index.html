Requirement 1

Pivot Tables

1. Create a Pivot Table and Pivot Chart to show the number of homes for sale broken down by Building Types. Which building type has the most homes for sale?

  1. Insert a PivotTable from the dataset.
  2. Drag BldgType into the Rows area.
  3. Drag a field (like Id) into the Values area and ensure it is set to "Count".
  4. Insert a Pivot Chart (e.g., Column chart) to visualize the result.
Correct Answer: A. 1Fam

2. Create a Pivot Table to show the average living area (GrLivArea) of homes, filtering for BldgType = 1Fam, and grouping YearBuilt from 1900 to 2010 in 10-year intervals. Which decade has the smallest average living area?

  1. Insert a PivotTable from the dataset.
  2. Drag YearBuilt into the Rows area.
  3. Right-click on any year in the table -> Group… (Start: 1900, End: 2010, By: 10).
  4. Drag GrLivArea into the Values area. Change Settings to Average.
  5. Drag BldgType into Filters -> Select 1Fam.
Correct Answer: C. 1950-1959

Requirement 3

Box & Whisker Plot of Sale Price

Interpretation Guide: Outliers & Skewness

A Box & Whisker Plot visualizes the distribution of data. In Excel, these are drawn vertically by default.

×
← Outlier
← Max
← Q3 (75%)
← Mean (×)
← Median
← Q1 (25%)
← Min

Interpreting Skewness with Boxplots

Right Skewed (Positive)
×
Mean > Median
Left Skewed (Negative)
×
Mean < Median

Tip: Click "Play Animation" to see how the vertical box plot logically maps onto the distribution curve.

  1. Copy the SalePrice data into a new sheet (Name it "Req 3").
  2. Select the SalePrice data range.
  3. Go to Insert > Charts > Box and Whisker (or found under Statistical Charts).

1. Are outliers above or below the center of the distribution?

Correct Answer: A. Above

2. The box in the plot spans from approximately 129,925 to 214,000. What does this range represent?

Correct Answer: B. The interquartile range (IQR)

Requirement 6

Z-Scores & Outliers

Calculate Z-score for SalePrice. An outlier is mathematically defined here as an absolute value of the Z-score > 3 (|Z-score| > 3).

  1. Generate Descriptive Statistics (Mean and Standard Deviation) for SalePrice.
  2. Create a calculated column "Z-score". Formula: =(SalePrice - Mean) / Standard Deviation (Make sure to use absolute references $ for Mean and StdDev).
  3. Create a conditional column flagging outliers. Example: =IF(ABS([Z-score])>3, "Yes", "No").
  4. Use =COUNTIFS([Range], "Yes") to count the total outliers (do not use COUNTIF).

1. How many outliers are present? (Hint: Use COUNTIFS)

Correct Answer: 18
