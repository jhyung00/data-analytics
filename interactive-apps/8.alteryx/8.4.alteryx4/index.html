0. Setup & Objectives

Recap: Last class we focused on summary calculations and conditional statements.
Today's Goal: Learn how to combine datasets so we can answer questions that one table alone can't.

We’ll learn four tools that all combine data—but in different directions:

  • Union = stack down (more rows)
  • Join / Append = combine across (more columns)
  • Find Replace = translate / map values using a lookup table

1. Union Tool Overview

Concept: Union stacks datasets vertically—same idea as 'append rows'. It works best when your inputs have a consistent column structure.

Configurations:
  • - Auto Config by Name: Aligns columns with identical names.
  • - Auto Config by Position: Aligns columns strictly by order.
  • - Manually Configure: You pick which columns stack together. The first input effectively 'sets' the field names.

3. Join Tool Overview

Concept: Join combines datasets horizontally—adding columns based on matching keys. It is picky: type must match, and values must match exactly (case matters).

The tool outputs three incredibly useful streams:

  • J (Matched): Records present in both inputs.
  • L (Left-only): Records from the left input with no match on the right.
  • R (Right-only): Records from the right input with no match on the left.

5. Duplication With Join

Warning: This is the #1 join surprise: duplicates multiply. When both sides have duplicates, you get a many-to-many join—and rows can explode.

If "Jim" appears 2 times on the left and 3 times on the right...

6. Append Fields Tool

Concept: Used to apply specific cell info (like a single parameter or warehouse location) to an entire dataset. It purposefully performs a Cartesian join (every T record joins to every S record).

Danger: 300 records in T × 10 records in S = 3,000 output records.

7. Find Replace Tool

Concept: Find Replace is a mapping tool. It converts values in one dataset using a lookup dataset (like VLOOKUP).

  • F Anchor: The data you are searching
  • R Anchor: The lookup/mapping table

The tool outputs matched/replaced records, and optionally flags "No Matches" so you can fix gaps in your lookup table.

8. Big Takeaways

The skill isn’t memorizing tools—it’s choosing the right one for the job:

  • Union = Add rows (stack data).
  • Join = Match keys to add columns.
  • Append Fields = Apply small sets of constants to all rows.
  • Find Replace = Map/standardize values using a lookup.

Tool Reference Guide

Union

Stacks datasets vertically.

Join

Matches records across two datasets on specific keys.

Append Fields

Cartesian join applying small sets of values everywhere.

Find Replace

Lookup and replace values via mapping tables.
