Lab Notes & Observations
Instructor Key: Initial Investigation
Potential student responses on the table's current state:
  • Each respondent is their own column. Organized so the question is stated first, with the response on the next row of that column.
  • Employees are answering different numbers of questions.
  • Q16, Q21, Q25, Q30 are only being answered by managers.
  • Q6 and Q24 have open responses that follow (Q6B, Q24B) when someone scores one of those questions very low.
  • The question numbers go up to 32, but the first 4 are identifying information, and there are the two additional open-ended questions for some.
  • There are three different departments taking part in the survey.
  • There are 45 respondents.
Ideal responses to the end goal:
  • The table is flipped. Each respondent should have their own row. A row should correspond to a single observation.
  • Each column should pertain to a single question (e.g. all responses to Q10 align in a single column).
  • Since not every respondent answers every question, there will be some blanks. We DO NOT want to replace those blanks with zeros, which would indicate a score of 0 when they simply weren't asked.
