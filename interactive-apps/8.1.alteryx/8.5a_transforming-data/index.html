The Problem: If subjects are spread across multiple columns (Math, Science), visual tools like Tableau or PowerBI can't create a "Subject" color legend, because "Subject" isn't a true variable column!
The Solution: The Transpose tool forces the variables (Subject and Score) into their own dedicated columns. Now the machine can group, filter, and chart them easily.

Example 1: Intro to Pivoting (Retail Orders)

Step 1 & 2: Input & Formula

Load orders_demo.csv. Use a Formula tool to calculate a new field: Revenue = [Units] * [UnitPrice]. This makes the Cross Tab feel like a real-world aggregation.

Step 3: Cross Tab (Wide Pivot)

Goal: "Units by Region and ProductCategory"

  • Group by: Region
  • Column Headers: ProductCategory
  • Values: Units
  • Method: Sum

Step 4 & 5: Transpose & Clean (Long/Tidy)

Take the Cross Tab output and "unpivot" it back to a long format using Transpose.

  • Key Fields: Region
  • Data Fields: Beverages, Snacks

Finally, use a Select tool to rename Name → ProductCategory and Value → TotalUnits.

Example 2: Handling Nulls (Campus Clubs)

Step 1 — Input Data

Load campus_club_activity.csv. The data contains student info, their club, the type of activity (Event, Meeting, etc.), and hours spent.

Step 2 — Cross Tab Example (Pivot Table Concept)

Goal: Find total hours spent in each club broken down by activity.

  • Group by: Club
  • Column Headers: ActivityType
  • Values: HoursSpent
  • Method: Sum

When you run this, you will immediately notice [Null] values where a club didn't participate in a specific activity.

Step 3 — Teach Handling NULL Values

Use the Data Cleansing tool to replace Nulls with 0s. Now the table becomes much easier to read and calculate with downstream.

Step 4 — Transpose Example (Wide → Long)

Now let's push the cleaned summary back into a long format using the Transpose tool.

  • Key Fields: Club
  • Data Fields: Event, Meeting, Tournament, Workshop

Followed by a Select tool to rename Name → ActivityType and Value → TotalHours.

Advanced: Employee Survey

The Situation: The company wants to improve employee retention. They sent out an employee satisfaction survey to understand where improvements could be made.

The survey provides a series of statements across seven categories, and respondents rate their feelings from 1-10 (10 being the highest).

  • Category breakdown: Provided in Category Lookup Table.csv.
  • Survey responses: Provided in Survey Response Data.xlsx (currently in an odd format).
The Goal:
1. Transform the raw data into a consistent tabular format.
2. Aggregate the data to find the average responses by category and department.

Survey: Initial Investigation

Current State of the Data

  • Each respondent is their own column. The question is stated first, with the response on the next row.
  • Employees answer different numbers of questions (some only for managers, etc.).
  • The first 4 rows are identifying information, followed by numbered questions.

The Ideal End Goal

  • Flipped Table: Each respondent should have their own row (one row = a single observation).
  • Column Alignment: Each column pertains to a single question.
  • Handling Blanks: Since not everyone answered every question, leave blanks as nulls. DO NOT replace with zeros!

Survey: Initial Transformations

Objective: Align the questions and their accompanying responses into the same record.

Step 1: Record ID

Adds a sequential number to keep track of which rows go together (e.g. Row 1 & 2 go together).

Step 2: Filter

Split into two streams using condition IsInteger([Record ID] / 2). Even rows = Answers (True anchor). Odd rows = Questions (False anchor).

Step 3: Formula

Add 1 to the Record ID of the Questions stream so they match the Answer stream.

Step 4: Transpose (x2)

Pivot columns into rows so we have exactly one question per respondent per row.

Step 5: Join

Join the streams back together using Record ID and Name. Now questions and answers are aligned horizontally!

Survey: Pivot Back to Tabular Data

Objective: Make questions the headers, and respondents the rows.

Step 6: Sort

Ensure questions are ordered correctly before pivoting.

Step 7: Cross Tab

Group by Name, Change Column Headers to the Question field, Values to the Answer field.

Step 8 & 9: Select / Dynamic Rename

Clean up headers, drop null columns, and change data types to Int16.

Survey: Analysis & Aggregation

Objective: Find the average response by question category and department.

Step 10: Transpose

Pivot the clean data again to make a "Question" column so we can join our lookup table.

Step 11 & 12: Join Lookup & Cross Tab Averages

Join the Category Lookup Table.csv to attach Categories (e.g., Q1 -> Accountability). Then Cross Tab grouping by Department, Header by Category, and Aggregating by Average.

Survey Findings & Discussion

Cautiously interpret averages (distributions matter, but bounded 1-10 scales limit outlier impact).

High Performers:

Accountability, Compensation, and Culture score well generally.

Top Department:

Sales Support is the most satisfied overall.

Problem Areas:

Communication and Management Performance are scoring poorly for the Sales department.
