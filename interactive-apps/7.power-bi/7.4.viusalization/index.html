Scenario 1

Revenue Trend

We have 36 months of revenue data. The CFO asks: "Is our growth seasonal or steady?"

Which visual fits?

Correct! For continuous data over time (36 months), a Line Chart is superior because the slope of the line instantly communicates the rate of change.

Branch Performance

We have 30 Sales Branches. We need to compare their total Revenue side-by-side to find the leaders.

Which visual fits?

?

Select the correct chart type

Correct! A Column Chart allows for easy magnitude comparison of discrete categories (Branches).

Scenario 3

Detailed Expenses

30 Cost Centers with long names (e.g., "North American Logistics Hub"). We need to rank them by spend.

Which visual fits?

?

Select the correct chart type

Correct! A Horizontal Bar is best here. It gives horizontal space for long labels, making them readable without tilting your head.

Scenario 4

Payment Delays

100 Invoices. We don't care about individual invoices; we care about the distribution of days late.

Which visual fits?

?

Select the correct chart type

Correct! A Histogram buckets the 100 data points into ranges (bins), showing the shape of the distribution.

Scenario 5

Simple Composition

We have 30 small expense items, but we just want to show the major split: Fixed vs Variable costs.

Which visual fits?

?

Select the correct chart type

Correct (with caution)! A Pie Chart is okay here ONLY because we aggregated the 30 rows into 2 simple slices. Never chart 30 slices.

Scenario 6

Budget vs Actual

36 Months. We need to see the Revenue Amount ($) AND the Variance (%) relative to budget simultaneously.

Which visual fits?

?

Select the correct chart type

Correct! A Combo Chart (Line and Clustered Column) lets you plot two different scales (Dollars and Percentage) on the same X-axis.

Scenario 7

Audit Risk

50 Transactions. We need to find outliers: High Dollar Value AND High Error Rate.

Which visual fits?

?

Select the correct chart type

Correct! A Scatterplot is the only standard chart that plots two numerical variables against each other to reveal correlation and outliers.

Scenario 8

P&L Walk

Showing how we start at Gross Revenue, deduct COGS/Expenses, and arrive at Net Income.

Which visual fits?

?

Select the correct chart type

Correct! A Waterfall Chart explains the cumulative effect of sequential positive and negative values.

  1. Click "Copy Data" to grab the dataset.
