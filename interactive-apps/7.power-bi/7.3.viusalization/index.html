Power BI Build Guide

Import the data you looted from the vault. Follow these pro-level blueprints to construct irrefutable visual evidence.

Blueprint 01

Useful Life Manipulation

Target Data: Fixed_Assets.csv

  • Add a Line and Clustered Column Chart to the canvas.
  • Drag Acquisition_Date to the X-axis (Set to Year hierarchy).
  • Drag Asset_ID to Column Y-axis (Set to Count).
  • Drag Useful_Life_Months to Line Y-axis (Set to Average).
  • Pro Tip: Use the On-Object Format Pane to thicken the line stroke to 4px, ensuring the "Useful Life" trend dominates the visual hierarchy.

"Watch the line. The average useful life of 'Heavy Machinery' suddenly spikes to 120 months right when profits dipped. You caught them."

Blueprint 02

Threshold Abuse

Target Data: Fixed_Assets.csv

  • Right-click Capitalized_Amount in the data pane -> select Create Group. Set Bin size to $100.
  • Add a Clustered Column Chart.
  • Place your new Amount (bins) on the X-axis and Asset_ID (Count) on the Y-axis.
  • Pro Tip: Add a vertical Reference Line at exactly $5,000 using the Analytics pane and color it bright red.

"A massive, unnatural cliff forms right before the red $5,000 line. This proves deliberate invoice splitting."

Blueprint 03

Ghost Margins

Target Data: Inventory.csv

  • Create a new DAX measure:
    Total_Value = SUMX('Inventory', 'Inventory'[Quantity_On_Hand] * 'Inventory'[Unit_Cost])
  • Add a Scatter Plot.
  • X-Axis: Days_In_Inventory. Y-Axis: Total_Value. Values: SKU.
  • Pro Tip: Enable Modern Visual Tooltips so hovering immediately reveals the specific SKU hiding in the top right.

"The top-right quadrant isolates the ghosts: Inventory that is extremely old AND highly valued, severely overstating company assets."

Blueprint 04

Rogue Entries

Target Data: Journals.csv

  • Add a Matrix Visual to the canvas.
  • Place Day_of_Week on Rows and Hour_of_Day on Columns. Place Entry_Amount in Values.
  • Use the Format Pane -> Cell Elements to turn on Background Color conditional formatting.
  • Pro Tip: Add an Input Slicer and bind it to User_Role. Type "CFO" to instantly filter the heatmap.

"The matrix immediately lights up bright red late on a Saturday night. A textbook management override of internal controls."
