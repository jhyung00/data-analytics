Download Lab Materials

Click "Download All" to get the 4 CSV files. Take a moment to understand the context of each file below before you begin the lab.

Fact Table

Raw_AP_Transactions.csv

The Messy Operational Data exported directly from an old ERP system.

Business Context

Notice the inconsistencies: "Staples" vs "STAPLES", dates like "1/15/2025" mixed with "2025-01-16", and amounts that include dollar signs randomly. Your job is to build an automated pipeline that catches and fixes these human-entry errors.

Mapping Table

Vendor_Alias_Map.csv

The "Translation Dictionary" created by the accounting team.

Business Context

Because AP clerks type "UPS 0039" and "U.P.S." randomly, a simple group-by won't work. We need this file to act as a bridge, converting all variations into a clean, unified name: United Parcel Service.

Dim Table

Vendor_Master.csv

The Official System of Record for Vendors.

Business Context

This table contains the golden data: VendorID and Category. But notice there are no messy names here. You cannot join this table to the raw data until you've successfully cleaned the raw vendor names in Part 2!

Control Table

Purchase_Orders.csv

The approved purchasing log used for internal audits.

Business Context

This is our audit test. We will compare the Amount billed in the AP Transactions against the PO_Amount approved here. Variances mean someone is over-billing us or bypassing procurement rules.

Part 1: Clean AP Table

Transforming messy inputs into reliable data types. (Steps 1 - 11)

Query: AP_Raw
1

Import Raw Data

Excel Ribbon → Data → Get Data → From Text/CSV.

Select Raw_AP_Transactions.csv → Click Transform Data (Not Load).

2

Rename Query

  • Right-click query name (on the left panel) → Rename.
  • New Name: AP_Raw
3

Clean Text & Numbers

  • Vendor: Select column. Transform tab → Format → Trim. (Repeat: Format → Clean).
  • Amount: Right-click column → Replace Values. Find $ and replace with (leave blank). Repeat: Find , and replace with (leave blank).
  • Amount: Click the 'ABC/123' icon in the column header → Data Type → Decimal Number.

Computers are literal. A leading space makes it an entirely different text string. " STAPLES " will not match with "STAPLES". Trimming invisible whitespace is the #1 fix for failed Joins.

7

Fix Dates

InvoiceDate: Click Type Icon (ABC) in header → Using Locale → Date (English US).

This elegantly handles mixed system formats like "1/15/2025" and "2025-01-16" simultaneously.

If dates remain formatted as "Text", you cannot sort them chronologically (e.g., February 2024 would sort alphabetically before January 2024), nor can you extract Month/Year for period-over-period reporting.

8

Standardize Dept & Terms

Dept (Right Click → Replace Values)
  • Finance → FIN
  • Fin → FIN
  • Operations/Ops → OPS
  • Warehouse → WH
Terms (Right Click → Replace Values)
  • NET30/Net30 → Net 30
  • DOR → Due on receipt
  • NET15 → Net 15

Checkpoint & Save

Verify your data types in the column headers before proceeding:

  • Dates are actual Dates (calendar icon).
  • Amount is Decimal (1.2 icon).
  • Depts are standardized to FIN/OPS/WH/IT.

Home Tab → Close & Load To... → Only Create Connection.

We don't want to load this messy intermediate step to the workbook yet. We have more joining to do!

Part 2: Merge & Report

Combining tables and building audit controls. (Steps 12 - 22)

12

Merge Alias Map

  1. Double click AP_Raw in Excel queries pane to re-open Power Query. Right click empty space in queries pane → New Query → File → Text/CSV → Vendor_Alias_Map.csv.
  2. Important: Transform Tab → Use First Row as Headers (if it didn't automatically).
  3. Clean VendorRaw column (Trim/Clean) just like we did earlier.
  4. Click back to AP_Raw. Home Tab → Merge Queries.
    Top table: AP_Raw (Click Vendor). Bottom table: Alias Map (Click VendorRaw). Join Kind: Left Outer.
  5. Click the expand icon on the new column header. Select only VendorName_Clean. Uncheck original column prefix.

An Inner Join drops any row that doesn't have a match. In accounting, we can't just "delete" an invoice because a vendor was missing from our map—that's how liabilities get understated! A Left Outer Join keeps all AP invoices and simply puts a "null" where mapping is missing, allowing us to flag it for review.

15

Merge Vendor Master

New Source → Text/CSV → Vendor_Master.csv. Clean the VendorName column (Trim/Clean).

Go back to AP_Raw. Merge Queries: AP_Raw (Select VendorName_Clean) ↔ Vendor Master (Select VendorName_Clean). Join Kind: Left Outer.

Expand the new column. Select: VendorID and Category.

17

PO Match Logic (3-Way Match Check)

  • New Source → Text/CSV → Purchase_Orders.csv.
  • Go back to AP_Raw. Merge Queries with Purchase Orders using the PO_Number columns. Expand to get PO_Amount.
  • Add Column Tab → Conditional Column (Name it POMatchStatus):
    • If PO_Amount is null Then No PO
    • Else If Amount equals [Select Column: PO_Amount] Then Match
    • Else Then Mismatch

It means the business spent money without getting pre-approval from procurement. This is a massive red flag for unauthorized spending, maverick purchasing, or potential fraud. It requires immediate manager review.

20

Duplicate Check Strategy

  1. Right-click AP_Raw in left pane → Duplicate (Do NOT use Reference here).
  2. Rename this new query to DupCounts.
  3. Select VendorName_Clean and Amount. Right click header → Remove Other Columns.
  4. Home Tab → Group By.
    Group by: VendorName_Clean AND Amount (use Advanced to add grouping). New column name: 'Count'. Operation: Count Rows.
  5. Go back to AP_Raw. Merge Queries. Join to DupCounts. Click both VendorName_Clean + Amount in top, hold CTRL, click both in bottom. Expand the Count column.
  6. Add Conditional Column named DuplicateRisk: If Count > 1 then TRUE else FALSE.

Yes, recurring flat-fee services (like a $50/mo internet bill) will have identical amounts. However, seeing the exact same dollar amount billed by the exact same vendor on the same day/week is the most common fingerprint of a duplicate invoice submission. It's a risk indicator, not a guarantee.

21

Exception Report & Final Output

  • Right-click AP_Raw → Reference (Creates a linked view). Rename it Exception_Report.
  • Add Conditional Column ExceptionFlag: Catch unmapped Vendors (VendorID is null), Mismatches, or DuplicateRisk=TRUE.
  • Filter the ExceptionFlag column to keep only the Exceptions.
  • Rename your main AP_Raw to Clean_AP_Transactions.
  • Home Tab → Close & Load To: Choose Table, load both the Clean table and Exception Report to New Worksheets.
Lab Complete! You built an automated ETL and Audit pipeline.

Instructor Script & Key

Step-by-Step Instructor Guide (No Missed Steps)

Part 0 — Setup:
  1. Unzip dataset to one folder.
  2. Open Excel → Blank Workbook → Save as PQ_ETL_Lab.xlsx.
Part 1: Clean (50 min)
  • 1. Import: Data → Get Data → CSV → Raw_AP_Transactions.csv → Transform.
  • 2. Rename: Query name to AP_Raw.
  • 3. Vendor: Transform → Format → Trim, then Clean.
  • 4. Amount: Replace Values $ → (blank). Replace , → (blank). Data Type → Decimal Number.
  • 5. Date: Data Type → Date (Use Locale if needed).
  • 6. Dept: Replace Values (Fin→FIN, Ops→OPS, Warehouse→WH).
  • 7. Terms: Replace Values (NET30→Net 30, DOR→Due on receipt).
  • 8. Save: Close & Load To... → Only Create Connection.
Part 2: Merge & Report (50 min)
  • 9. Alias Map: New Source CSV → Vendor_Alias_Map.csv. Use First Row Headers. Clean VendorRaw.
  • 10. Merge 1: AP_Raw (Vendor) ↔ Alias (VendorRaw). Expand VendorName_Clean.
  • 11. Master: New Source CSV → Vendor_Master.csv. Clean VendorName.
  • 12. Merge 2: AP_Raw (Clean Name) ↔ Master (Clean Name). Expand ID, Category.
  • 13. POs: New Source CSV → Purchase_Orders.csv. Merge on PO_Number. Expand Amount.
  • 14. Logic: Add Conditional Col POMatchStatus (Match/Mismatch/No PO).
  • 15. Duplicates: Right-click AP_Raw → Duplicate. Group By (Vendor+Amount). Merge back.
  • 16. Exception Report: Reference AP_Raw. Filter for Mismatches/Nulls.
  • 17. Final Load: Load AP_Raw and Exception_Report as Tables.
