Part 1: Internal Control Testing (Basic Logic)

Perform standard control tests to flag simple inventory management issues.

  • Basic 1. Reorder Flag
    IF
    Create column "Action". If EndingStock is less than 10, display "Reorder". Otherwise, display "Sufficient".
  • Basic 2. Calculate Average Price
    IFERROR
    Create column "Avg Price". Formula: TotalSales / UnitSold. Wrap this in an IFERROR to display 0 if division by zero occurs.
  • Intermediate 3. Stock Status (Turnover Analysis)
    NESTED IF
    Create column "Stock Status":
    • If EndingStock > 60, display "Overstock".
    • If EndingStock < 5, display "Critical Low".
    • Otherwise, display "Normal".

Part 2: Inventory Roll-Forward (Reconciliation)

Verify if the client's reported ending stock matches the transaction history.

  • Basic 4. Independent Recalculation
    FORMULA
    Create column "Calc Ending Stock". Formula: BeginningStock + Purchase - UnitSold.
  • Basic 5. Discrepancy Check
    IF
    Create column "Audit Flag". If your calculated stock equals the client's EndingStock, display "Verified". Else, display "Error".

Formula Reference Library

This section maps the audit logic to the specific Excel syntax used in the answer key.

Part 1: Internal Controls

Action Flag =IF(F2 < 10, "Reorder", "Sufficient")

Identifies inventory falling below safety stock levels.

Stock Status (Nested) =IF(F2 > 60, "Overstock", IF(F2 < 5, "Critical Low", "Normal"))

Categorizes inventory health into three buckets.

Part 2 & 3: Recon & Enrichment

Reconciliation Check =IF((Beg + Purch - Sold) = End, "Verified", "Error")

Validates the Ending Stock figure provided by the client.

Dept Code Lookup =XLOOKUP(Name, MasterTable[Name], MasterTable[Code], "Pending")

Links individual items to their Department via Master File.

Part 5: Manager's Challenge (Advanced)

Department Assessment Formula =IF(SUMIFS(TotalSales, DeptCol, CurrentDept) > 50000, "Core Segment", "Non-Core")

Logic Explained:
This formula doesn't just look at the row. It calculates the total sales for the entire department the item belongs to. If that department generates over $50k total, every item in that department gets flagged as "Core Segment".
