Part 1: Clean AP Table

Steps 1 - 11

AP_Raw
1

Import Raw Data

Excel Ribbon → Data → Get Data → From Text/CSV.

Select Raw_AP_Transactions.csv → Transform Data.

2

Rename Query

  • Right-click query name → Rename.
  • New Name: AP_Raw
3

Clean Text & Numbers

  • Vendor: Transform → Format → Trim, then Clean.
  • Amount: Replace Values $ with (blank). Replace , with (blank).
  • Amount: Transform → Data Type → Decimal Number.
7

Fix Dates

InvoiceDate: Click Type Icon → Using Locale → Date (English US).

Handles mixed formats like 1/15/2023 and 2023-01-16.

8

Standardize Dept & Terms

Dept (Replace Values) Finance → FIN
Fin → FIN
Operations/Ops → OPS
Warehouse → WH
Terms (Replace Values) NET30/Net30 → Net 30
DOR → Due on receipt
NET15 → Net 15

Checkpoint & Save

  • Dates are actual Dates (calendar icon).
  • Amount is Decimal (1.2 icon).
  • Depts are FIN/OPS/WH/IT.

Close & Load To... → Only Create Connection.

Part 2: Merge & Report

Steps 12 - 22

12

Merge Alias Map

  1. Open AP_Raw. New Source → Vendor_Alias_Map.csv.
  2. Important: Transform → Use First Row as Headers (if needed).
  3. Clean VendorRaw (Trim/Clean).
  4. Merge Queries: AP_Raw (Vendor) ↔ Alias (VendorRaw). Join: Left Outer.
  5. Expand: VendorName_Clean only.
15

Merge Vendor Master

New Source → Vendor_Master.csv. Clean name.

Merge: AP_Raw (VendorName_Clean) ↔ Master (VendorName_Clean). Left Outer.

Expand: VendorID, Category.

17

PO Match Logic

  • New Source → Purchase_Orders.csv.
  • Merge into AP_Raw on PO_Number. Expand PO_Amount.
  • Conditional Column (POMatchStatus):
    • If PO_Amount is null -> No PO
    • Else if Amount equals PO_Amount -> Match
    • Else -> Mismatch
20

Duplicate Check (Duplicate Strategy)

  1. Right-click AP_Raw → Duplicate (Do NOT use Reference).
  2. Rename new query to DupCounts.
  3. Keep VendorName_Clean, Amount. Remove Others.
  4. Group By: VendorName_Clean, Amount. Operation: Count Rows.
  5. Go back to AP_Raw. Merge DupCounts in. Expand Count.
  6. Conditional Column DuplicateFlag: If Count > 1 then TRUE else FALSE.
21

Exception Report & Output

  • Right-click AP_Raw → Reference → Rename Exception_Report.
  • Conditional Column ExceptionFlag: Catch null Vendors, Mismatches, or Duplicates. Filter to keep Exceptions.
  • Rename AP_Raw to Clean_AP_Transactions.
  • Close & Load To: Load both as Tables on New Worksheets.

Instructor Script

Step-by-Step Instructor Guide (No Missed Steps)

Part 0 — Setup:
  1. Unzip dataset to one folder.
  2. Open Excel → Blank Workbook → Save as PQ_ETL_Lab.xlsx.
Part 1: Clean (50 min)
  • 1. Import: Data → Get Data → CSV → Raw_AP_Transactions.csv → Transform.
  • 2. Rename: Query name to AP_Raw.
  • 3. Vendor: Transform → Format → Trim, then Clean.
  • 4. Amount: Replace Values $ → (blank). Replace , → (blank). Data Type → Decimal Number.
  • 5. Date: Data Type → Date (Use Locale if needed).
  • 6. Dept: Replace Values (Fin→FIN, Ops→OPS, Warehouse→WH).
  • 7. Terms: Replace Values (NET30→Net 30, DOR→Due on receipt).
  • 8. Save: Close & Load To... → Only Create Connection.
Part 2: Merge & Report (50 min)
  • 9. Alias Map: New Source CSV → Vendor_Alias_Map.csv. Use First Row Headers. Clean VendorRaw.
  • 10. Merge 1: AP_Raw (Vendor) ↔ Alias (VendorRaw). Expand VendorName_Clean.
  • 11. Master: New Source CSV → Vendor_Master.csv. Clean VendorName.
  • 12. Merge 2: AP_Raw (Clean Name) ↔ Master (Clean Name). Expand ID, Category.
  • 13. POs: New Source CSV → Purchase_Orders.csv. Merge on PO_Number. Expand Amount.
  • 14. Logic: Add Conditional Col POMatchStatus (Match/Mismatch/No PO).
  • 15. Duplicates: Right-click AP_Raw → Duplicate. Group By (Vendor+Amount). Merge back.
  • 16. Exception Report: Reference AP_Raw. Filter for Mismatches/Nulls.
  • 17. Final Load: Load AP_Raw and Exception_Report as Tables.
